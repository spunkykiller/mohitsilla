# Mohit Silla — personal website

A server-rendered personal profile built with Next.js and TypeScript.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run typecheck
npm run lint
npm run build
```

The site includes a homepage, an `/experiments` archive, social preview metadata, structured data, `robots.txt`, and a sitemap.
